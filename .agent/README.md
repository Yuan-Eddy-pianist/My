# Personal skill source

`skills/` contains only the owner's personally selected or maintained skills.
The collection includes custom workflows and separately installed third-party
skills. Application-supplied Codex and Cursor skills stay in their managed
installation paths.

Use the root `install-skills.sh` to create discovery links. The special Codex
canvas bridge points directly to Cursor's managed canvas; no canvas package is
stored here. See [layout and migration details](../docs/personal-skills-layout.md).
